# Play-test reports

Anonymous summaries of real play sessions. No names, photos, recordings or personal details (see [PRIVACY.md](../PRIVACY.md)).

Use one file per session: `YYYY-MM-DD-short-title.md`, with: game and pack, session length, questions answered and right, what felt good, what was annoying or confusing, bugs found (link the issues), and keep / change / drop.

The V1 verdict will be `v1-verdict.md` in this folder.
