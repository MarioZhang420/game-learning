# 0006: Apache-2.0 for code, CC BY-SA 4.0 for public packs

**Date:** 2026-11-21 · **Status:** Accepted

**Decision.** Code is Apache-2.0 (open, permissive, with a patent grant). Content packs we publish are CC BY-SA 4.0 (share and adapt with credit, same license). Copyrighted books and packs made from them are never published.

**Considered.** MIT (no patent grant), GPL-3.0 (keeps forks open but scares some contributors and companies).
