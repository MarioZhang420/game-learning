# Game Learning (working name)

An early, experimental open-source project: make the games people already play part of what they learn.

You keep playing your game (Hollow Knight, Minecraft, Terraria…). A companion app turns your own study material into short challenges and brings them in at good moments, such as after a death, before a boss, or during downtime. Correct answers earn rewards, at first inside the companion and later inside the game where an integration supports it.

**Status:** idea stage. There is no code yet, and the name, stack and first game are all undecided.

- Full concept: [docs/BRIEF.md](docs/BRIEF.md)

## First goal

Build one small prototype with one game and a basic learning loop:

import notes → generate questions → play → challenge → answer → feedback → reward

Then play with it ourselves and with friends, and keep only what feels good.
